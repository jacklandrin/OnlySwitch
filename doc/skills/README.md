# Project Skill Notes

Store project-specific skill supplements, routing notes, and reusable instructions here.

These files are not loaded automatically. Load a file only when the task matches its stated scope, such as TCA feature design, Swift 6 concurrency, macOS system effects, remote transport, widget integration, App Store review, or test strategy. Each file should begin with a short `When to load` section and should avoid duplicating general guidance that is not needed for the relevant task.
